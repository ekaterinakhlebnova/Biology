# Мини-конспект: pandas, работа с таблицей

## 0. Пути к файлам в Windows

`\` внутри строки — начало спецсимвола (`\n`, `\U`, `\1`...), поэтому путь ломается.

```python
pd.read_csv("C:/Users/1/Downloads/file.csv")     # прямые слэши
pd.read_csv(r"C:\Users\1\Downloads\file.csv")    # r"" — «сырая» строка
pd.read_csv("C:\\Users\\1\\Downloads\\file.csv") # экранирование
```

## 1. loc и iloc

| | `loc` | `iloc` |
|---|---|---|
| обращается по | **меткам** (названия столбцов, метки индекса) | **позициям** (номера с нуля) |
| срез `a:b` | включает `b` | не включает `b` |

Порядок всегда `[строки, столбцы]`, `:` = «все».

```python
df.iloc[:, 1:]              # все строки, столбцы начиная со второго
df.iloc[:3]                 # первые три строки
df.loc[5, "gene symbol"]    # одна ячейка: строка с меткой 5, столбец по имени
df.loc[5, "gene symbol"] = "STAT3"   # так же можно записать значение
```

`loc` и `iloc` — индексаторы, поэтому скобки **квадратные**.
`insert`, `mean`, `concat` — методы/функции, скобки **круглые**.
Ошибка `'method' object is not subscriptable` = поставили `[]` вместо `()`.

## 2. axis

`axis` — вдоль какой оси «схлопываем» таблицу.

```python
df.mean(axis=0)   # идём вниз по строкам  -> одно число на каждый СТОЛБЕЦ
df.mean(axis=1)   # идём вправо по столбцам -> одно число на каждую СТРОКУ
```

Запоминалка: результат `axis=1` по длине равен числу строк, значит он годится
как новый столбец; результат `axis=0` — как новая строка.

## 3. Добавить столбец

```python
df["Mean"] = df.iloc[:, 1:].mean(axis=1)     # в конец
df.insert(1, "Mean", значения)               # в позицию 1 (счёт с нуля)
```

`insert` меняет таблицу на месте и возвращает `None`,
поэтому **нельзя** писать `df = df.insert(...)`.

## 4. Добавить строку

В конец:

```python
df.loc[len(df)] = [...]      # список: значений ровно столько, сколько столбцов
df.loc[len(df)] = series     # Series: раскладывается по НАЗВАНИЯМ столбцов,
                             # чего нет в Series -> NaN
```

- `len(df)` — безопасная метка: индексы идут с 0, значит `len(df)` ещё свободна.
- Если метка уже существует, `loc` не добавит строку, а **молча перезапишет** старую.
- Список неправильной длины -> `ValueError: cannot set a row with mismatched columns`.

В середину — готового метода нет, режем и склеиваем:

```python
new = pd.DataFrame([[...]], columns=df.columns)
df = pd.concat([df.iloc[:3], new, df.iloc[3:]], ignore_index=True)
```

`ignore_index=True` — перенумеровать строки заново (иначе метки будут 0,1,2,0,3,4...).

Если порядок не принципиален — проще добавить в конец и отсортировать:
`df = df.sort_values("gene symbol")`.

## 5. Порядок действий важен

Столбец со средним считается в момент выполнения строки. Строки, добавленные
позже, в расчёт не попадут — сначала добавляем данные, потом считаем.
